Beyond Types: Relative Effects

The same delay resolves the latent effect of a function at the call. 

  def trace[A, B, E](f: A -> B | E, x: A): B | io ▷ E     = { log(x); f(x) }
  def trace[F](f: F, x: Dom(F)): Range(F) | io ▷ [h[Eff(F)]]  = { log(x); f(x) }
$\cTEff{A \to B \mid e} \equiv e \qquad\quad \inferfrac{f : F \mid e_1 \qquad x : \cTDom{F} \mid e_2}{f(x) : \cTRange{F} \mid e_1 \rhd e_2 \rhd \chl{\cTEff{F}}}$
$\cTEff{F}$ is covariant, like $\cTRange{F}$, so its delay is the easier one.
The relative effect pure(f), pure except for calling f, is then just $\cTEff{F}$. Rytz, Odersky and Haller, ECOOP'12; the formal development is future work

An Idea: Inference by Delay

Delay never splits $F$, so inference could keep it whole.
Example: calling $\textit{eta}(\textit{inc})(1)$, with $\textit{inc} : \TInt \to \TInt$: local inference solves as few constraints as it can and checks the rest (Pierce and Turner, TOPLAS 2000)
type of $\textit{eta}$ solve check
$\forall A, B.\ (A \to B) \to A \to B$ $\TInt \to \TInt <: A \to B \qquad \TInt <: A$ nothing
$\forall F.\ F \to \cTDom{F} \to \cTRange{F}$ $\TInt \to \TInt <: F$ $\TInt <: \cTDom{F}$
So local inference solves only the constraint from $\textit{inc}$, and checks $1$ against $\cTDom{F}$. open: constraints between projections, as in $f(f(x))$, principal types, and overloads typed by intersections
