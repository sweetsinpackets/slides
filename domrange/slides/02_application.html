Root Cause: Application Asks for an Arrow

The standard application rule can apply $f$ only when its type is an arrow.
$\inferfrac{f : \chl{A \to B} \qquad x : A}{f(x) : B}\ \ \rulefmt{T-App}$
An abstract $F$ stays abstract at the definition: its future instantiations are unknown.

This Work

An alternative view from mathematics: a function maps its domain to its range.
$x \in \mathrm{dom}(f) \;\Longrightarrow\; f(x) \in \mathrm{ran}(f)$
This work proposes a refined application rule for lightweight polymorphism.
$\inferfrac{f : A \to B \qquad x : A}{f(x) : B}$ standard
$\inferfrac{f : F \qquad x : \cTDom{F}}{f(x) : \cTRange{F}}$ proposed
The η-expansion then gets the precise type, without exposing the shape of $F$.
$\textit{eta} \;:\; \forall F <: \TTop.\ F \to \chl{\cTDom{F}} \to \chl{\cTRange{F}}$
