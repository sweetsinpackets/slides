Delay: No Shape Exposure

Our rule types the application $f(x)$ with $f : F$, never exposing the arrow shape.
$\inferfrac{\inferfrac{f : F}{f : \chl{\TDom{F} \to \TRange{F}}}\ \eta \qquad x : \cTDom{F}}{f(x) : \cTRange{F}}$ type destructors
$\inferfrac{f : F \qquad x : \cTDom{F}}{f(x) : \cTRange{F}}$ ours
Type destructors first cast $f$ to an arrow, which needs an arrow bound. Hofmann and Pierce, I&C 2002, who only named the destructors for arrows

Delay: No Reconstruction

The converse cast reconstructs $F$, as TypeScript code does with as F: 

  const logDecorator = <F extends (...args: any) => any>(fn: F) =>
    ((...args: Parameters<F>) => fn(...args)) [h[as F]];
  const taggedInc = Object.assign((x: number) => x + 1, { tag: "inc" });
  logDecorator(taggedInc)[h[.tag]].toUpperCase()   // type-checks, !!throws at run time!!
The cast is unsound once a function type describes more than its calls.
Delay needs neither cast, so the wrapper keeps its type $\cTDom{F} \to \cTRange{F}$: 

  logDecorator(taggedInc)[h[.tag]].toUpperCase()   // !!error:!! the wrapper has no field tag

Delay: The Argument Witnesses the Arrow

$\cTDom{F}$ can only reduce to an inhabited type if $F$ is an arrow type:

an arrow

$\cTDom{\TInt \to \TBool} \equiv \TInt$
has values, such as $42$

other types

$\cTDom{\TInt} \qquad \cTDom{\TTop}$
do not reduce, and have no values
So $x : \cTDom{F}$ certifies the arrow at the call.
Call-by-value evaluates the argument first:
$f(e) \longrightarrow^* f(\chl{v}) \qquad v : \cTDom{F}$

Delay Is Unique to Contravariance

Projections follow the variance of their type:

function

$F <: A \to B \;\Rightarrow\; A <: \cTDom{F}$
$v : \cTDom{F}$ only if $F$ is below an arrow

pair

$A \times B <: P \;\Rightarrow\; A <: \TFst{P}$
$v : \TFst{P}$ even if $P$ is $\TTop$
So only a contravariant projection can wait for a witness from outside:
$\Lambda F <: \TTop.\ \lambda f : F.\ \lambda \chl{x} : \cTDom{F}.\ f(x)$
witness from outside: $\chl{x}$ at the call
$\Lambda X <: \chl{\TTop \times \TTop}.\ \lambda p : X.\ p.1 \;:\; \TFst{X}$
witness from inside: only the bound

Boundless Quantification

The two ingredients take over both roles of an arrow bound $F <: A \to B$.
types $A$, $B$ Projection $\cTDom{F}$ and $\cTRange{F}$ name them
shape $\to$ Delay the argument witnesses it at the call
So $F$ needs no meaningful bound, and the proposed rule types $\textit{eta}$:
$\textit{eta} \;:=\; \Lambda F <: \chl{\TTop}.\ \lambda f : F.\ \lambda x : \cTDom{F}.\ f(x)$
$\inferfrac{\inferfrac{f : F \qquad x : \cTDom{F}}{f(x) : \cTRange{F}}\ \rulefmt{T-App-DR}}{\textit{eta} \;:\; \forall F <: \TTop.\ F \to \cTDom{F} \to \cTRange{F}}\ \rulefmt{T-TAbs}$
at $\TInt \to \TBool$, the projections eliminate, and $\textit{eta}$ has the type $(\TInt \to \TBool) \to \TInt \to \TBool$
